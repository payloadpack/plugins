- A parent is a document of the same collection. You set [per collection](/path/configuration/#collections) where the parent comes from: the plugin's own field, Payload's hierarchy, or nowhere. A top-level document's path starts at its collection's [base path](/path/configuration/#collections), or at the root.
- The path is stored on the document and indexed. Only the plugin writes it, and it ignores any value a save sends for it.
- The top-level page with the slug `home` is the [home page](/path/configuration/#home-page). Its path is `/`.

## One document per path

> Page "Plan A" is already at this path, so change the slug or the parent.

- Each path belongs to one document, across all collections and statuses, drafts included. Only a document in the trash takes no path.
- The plugin [refuses](/path/refusals/#taken-paths) a taken path with the message above. Two documents can still have the same slug below different parents, such as `/north/contact` and `/south/contact`.
- A duplicate gets the original's slug plus `-copy`, such as `/about-copy`. If that is taken below the same parent, it gets `-copy-2` and up.

<details>
<summary>Good to know</summary>

Each save checks the path before it writes. So two saves of the same path at the same moment can both pass. [Limits](/path/limits/) shows what you see then and what to do.

</details>

## The slug

| An editor types, or the title is   | The saved slug  |
| ---------------------------------- | --------------- |
| `Opening Hours`, as the title only | `opening-hours` |
| `Summer Sale!`                     | `summer-sale`   |
| `Vår historia`                     | `var-historia`  |
| `Новости`                          | `новости`       |

- Every save cleans the slug, with your own [`slugify`](/path/configuration/#slugify) if you set one.
- A save that clears the slug keeps the old one. A new title never changes it. So a published URL never changes by itself.
- The field is Payload's own slug field: locked until the editor unlocks it, with a button that makes the slug from the title.

<details>
<summary>Good to know</summary>

- A typed slug that cleaning leaves empty, such as `!!!`, counts as no slug.
- A collection without `admin.useAsTitle` has nothing to make a slug from.

</details>
