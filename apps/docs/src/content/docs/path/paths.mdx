- **Same-collection parent**: A document's parent is always in the same collection. Configure [per collection](/path/configuration/#collections) whether it uses the plugin's `parent` field, Payload's hierarchy, or no parent. Top-level documents start at the collection's [base path](/path/configuration/#collections) or `/`.
- **Read-only & indexed**: `path` is stored on the document and indexed. Only the plugin writes it — any `path` value sent on save is ignored.
- **Home page**: The top-level page with the slug `home` is the [home page](/path/configuration/#home-page) at `/`.

## One document per path

- **Unique across all collections:** Every path belongs to one document across all configured collections (`pages`, `posts`, etc.) and statuses, drafts included. Documents in the trash don't take a path.
- Picking a taken path is [refused](/path/refusals/#taken-paths) with the message above. Documents under different parents can share a slug, like `/north/contact` and `/south/contact`.
- Duplicating a document appends `-copy` (e.g. `/about` → `/about-copy`, or `-copy-2` and up if already taken under the same parent).

<details>
<summary>Concurrent saves</summary>

Each save checks the path before writing, so two saves of the same path at the exact same instant can both pass. See [Limits](/path/limits/) for what happens and how to fix it.

</details>

## The slug

| Title or typed slug          | Saved slug                 |
| ---------------------------- | -------------------------- |
| `Opening Hours` (title only) | `opening-hours`            |
| `Summer Sale!`               | `summer-sale`              |
| `Vår historia`               | `var-historia`             |
| `Новости`                    | `новости`                  |
| `!!!` (cleaned to empty)     | _(none — counts as empty)_ |

- Every save cleans the slug (using your [`slugify`](/path/configuration/#slugify) if set).
- Clearing the slug keeps the current one, and editing the title never changes the slug — published URLs never change on their own.
- Uses Payload's slug field UI: locked until unlocked, with a button to generate from the title. Collections without `admin.useAsTitle` have no title to generate from.
