- A parent is a document of the same collection. Whether it comes from the plugin's own field, Payload's hierarchy or nowhere is set [per collection](/path/configuration/#collections). A top-level document starts at its collection's [base path](/path/configuration/#collections), or at the root.
- The path is stored on the document and indexed. Only the plugin writes it, so a value a save sends for it is ignored.
- The top-level page with the slug `home` is the [home page](/path/configuration/#home-page), at `/`.

## One document per path

> Page "Plan A" is already at this path, so change the slug or the parent.

- A path belongs to one document, in any collection and of any status, drafts too. Only a document in the trash takes no path.
- A taken path is [refused](/path/refusals/#taken-paths) with the message above. Two documents may still share a slug below different parents, such as `/north/contact` and `/south/contact`.
- A duplicate gets its original's slug with `-copy`, such as `/about-copy`, or `-copy-2` and up when that is taken below the same parent.

<details>
<summary>Good to know</summary>

Each save checks the path before it writes, so two saves of the same path in the same instant can both pass. [Limits](/path/limits/) has what you see then and what to do.

</details>

## The slug

| An editor types, or the title is   | The saved slug  |
| ---------------------------------- | --------------- |
| `Opening Hours`, as the title only | `opening-hours` |
| `Summer Sale!`                     | `summer-sale`   |
| `Vår historia`                     | `var-historia`  |
| `Новости`                          | `новости`       |

- A slug is cleaned on every save, by your own [`slugify`](/path/configuration/#slugify) when you give one.
- A save that clears the slug keeps the one it had, and a new title never changes it, so a published URL never moves on its own.
- The field is Payload's own slug field: locked until the editor unlocks it, with a button that makes the slug from the title.

<details>
<summary>Good to know</summary>

- A typed slug with nothing left after cleaning, such as `!!!`, counts as no slug.
- A collection without `admin.useAsTitle` has nothing to make a slug from.

</details>
