## When a document moves

| An editor or your code                                               | The document's path                        |
| -------------------------------------------------------------------- | ------------------------------------------ |
| Saves a draft with a new slug or parent, on a published document     | Stays, with a pending move                 |
| Saves a draft with a new slug or parent, on one that isn't published | Moves at once, with the documents below it |
| Publishes the draft                                                  | Moves to the draft's path                  |
| Unpublishes the document                                             | Moves to the latest draft's path           |
| Updates it through the API without `draft`                           | Moves to the latest draft's path           |
| Restores a version                                                   | Gets the path from its parent and slug     |

- A pending move takes no path until it is published. The sidebar shows the path the document gets when the draft is published.
- Publishing checks that path again, because another document may be at it by then. Two pending moves can point to the same path. The first one published gets it.

## Autosave

An autosave is checked like any other save. A new document has no slug and no path until an autosave gives it a title. A draft without a slug can't be published.

## Previews

```ts
const found = await findByPath({ draft: true, path: '/plans', payload })
```

`findByPath` returns published documents. With `draft: true` it finds the latest draft at a path.
