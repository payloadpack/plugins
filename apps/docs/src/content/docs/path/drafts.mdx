## When a document moves

| Action                                                   | What happens to the path                   |
| -------------------------------------------------------- | ------------------------------------------ |
| Save a draft with a new slug or parent (published doc)   | Stays at current path, with a pending move |
| Save a draft with a new slug or parent (unpublished doc) | Moves immediately, along with its branch   |
| Publish the draft                                        | Moves to the draft's path                  |
| Unpublish the document                                   | Moves to the latest draft's path           |
| Update via the API without `draft: true`                 | Moves to the latest draft's path           |
| Restore a version                                        | Built from that version's parent and slug  |

- A pending move doesn't reserve its path. The sidebar shows the path the document will get when published.
- Publishing checks the path again, in case another document took it in the meantime. Two pending moves can target the same path — the first one published gets it.
- Older versions keep the paths they had.

## Autosave

- Autosaves run the same path checks as any other save.
- A new document has no slug or path until an autosave saves a title (or slug).
- A draft without a slug can't be published.

## Previews

```ts
const found = await findByPath({ draft: true, path: '/plans', payload })
```

`findByPath` returns published documents by default. Pass `draft: true` to find the latest draft at a path.
